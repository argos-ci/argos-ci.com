# Generating a changelog image

Changelog illustrations share one visual system: the official pastel gradient background with a detailed, layered product illustration painted on top — crisp enough to hold up on a retina screen at full width. The image is generated by `gpt-image-2` via the OpenAI **images/edits** endpoint, using the background as the base image so every entry sits on the exact same gradient.

## Inputs

- **Background**: `images/changelog-background.jpg` (3246×1800, ratio ≈ 1.80). Never commit a changelog image that isn't derived from it.
- **API key**: `ARGOS_OPENAI_API_KEY`, exported in `~/.zshrc`. It is NOT available in non-interactive shells — `source ~/.zshrc` before calling the API.
- **Output size**: `2592x1440` — same 1.8 ratio as the background, both dimensions divisible by 16 (a gpt-image-2 requirement), and 1.5× the `1728x960` older entries used, so the image stays sharp on retina screens. Flat illustrations compress well: a high-quality JPEG at this size is still only ~150 KB. Never upscale a smaller render — generate at this size.

## Steps

1. Resize the background to the output size (input and output must match so the gradient isn't distorted):

```bash
magick images/changelog-background.jpg -resize 2592x1440! /tmp/changelog-bg-input.png
```

2. Write the prompt (see style guide below), then call the edits endpoint. Generation takes 1–2 minutes:

```bash
source ~/.zshrc
curl -s https://api.openai.com/v1/images/edits \
  -H "Authorization: Bearer $ARGOS_OPENAI_API_KEY" \
  -F model=gpt-image-2 \
  -F image=@/tmp/changelog-bg-input.png \
  -F size=2592x1440 \
  -F quality=high \
  -F output_format=jpeg \
  -F "prompt=$(cat /tmp/changelog-image-prompt.txt)" \
  | python3 -c "import json,sys,base64; open('/tmp/changelog-out.jpg','wb').write(base64.b64decode(json.load(sys.stdin)['data'][0]['b64_json']))"
```

3. Review it twice, and iterate on the prompt until both pass:
   - **The whole image**, downscaled (`sips -Z 1100 …`): background gradient preserved, the concept reads in two seconds, the story is right (each element in the state the prompt asked for), generous margins.
   - **A 1:1 crop** of the busiest region (`magick out.jpg -crop 1450x790+950+500 crop.jpg`): edges crisp, no blur or smeared shapes, no JPEG blocking around glows, no letterforms or garbled glyphs.

   Install the generated file as is — re-encoding it only loses quality.

4. Install it:

```bash
mkdir -p public/assets/changelogs/<slug>
cp /tmp/changelog-out.jpg public/assets/changelogs/<slug>/<slug>.jpg
```

## Prompt style guide

Look at 1–2 recent images in `public/assets/changelogs/` (e.g. `scim-provisioning`, `journeys`) before writing the prompt. Then fill this template — keep every paragraph, only the **Concept** changes from one entry to the next:

> Keep the soft pastel gradient background exactly as provided — do not change its colors, and do not add texture, noise or a vignette. On top of it, paint a premium, highly detailed product illustration in the established Argos changelog style, as crisp as a polished retina UI mockup from a top product design team.
>
> Style: clean vector UI with real depth. White and very light grey rounded-corner cards (generous corner radius) with thin light-grey 1px borders, a faint white highlight along their top edge, and layered, realistic soft shadows — a tight contact shadow plus a wide, diffuse ambient one. A restrained palette: white, cool greys, and Argos purple (#8b5cf6 to #7c3aed) as the main accent, with green (#22c55e) and pink (#ec4899) used only for status. Accents may carry a very subtle gradient and a soft glow.
>
> Detail: fill every card with believable UI structure — avatars as soft pastel circles, list rows, small status dots, toggles, chips and pills, icons drawn with a consistent rounded 2px stroke — and replace all text with rounded grey placeholder bars of varied lengths, darker for titles and lighter for body text.
>
> Concept: [the feature-specific scene — see below].
>
> Composition: one clear focal point, depth from layers (secondary cards a little smaller and further back), balanced asymmetry, at least 12% margin on every side, nothing touching the edges.
>
> Rendering: sharp edges, smooth anti-aliasing, no blur except in shadows and glows, no photographic or 3D clay look, and absolutely no readable text, letters, numbers or logos anywhere.

Concept guidance:

- Depict the feature as an abstract product scene: UI windows, terminals, cards, connecting lines — not metaphors like rockets or lightbulbs.
- **Spell out the story element by element.** Name each card, how many rows it holds, and the state of every element that carries meaning (toggled on or off, a green plus badge, a row drifting away with a pink minus badge). A vague concept ("a directory syncing with a team") renders as tidy but empty cards that say nothing about the feature.
- Screenshot-diff imagery = side-by-side cards with pink dashed highlighted regions; approvals = green check circles; terminals = dark or white window with a `>` prompt and grey bars.
- Flows and integrations read well as a left-to-right composition with a glowing connector between two elements; put the focal card on the right, slightly larger and in front.
- **No readable text** in the image — gpt-image-2 text is a garbling risk, and the house style uses placeholder bars anyway. Well-known logos are the only exception, and only when essential.
